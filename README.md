# INSE-6450: AI-based Digital Advertising Optimization Using Uplift Modeling

This repository is the version-controlled codebase and project repo for the AI Systems Engineering (INSE6450) project focused on AI-based Digital Advertising Optimization Using Uplift Modeling.

The purpose of this repo is to organize and track the project work across the course milestones, including data preparation, modeling, experimentation, and analysis related to uplift modeling for digital advertising optimization.

## Project structure

Each folder in this repository represents a project milestone, and each milestone contains its own Google Colab notebooks for development and experimentation.

- `Milestone_1/` — first milestone work and notebook(s)
- `Milestone_2/` — second milestone work and notebook(s)

## Notes

- This repository is intended to preserve a disciplined, version-controlled history of the project.
- Google Colab notebooks are used for iterative analysis, model prototyping, and milestone deliverables.
- Additional milestones and supporting files may be added as the project evolves.
