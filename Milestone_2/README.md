## How to run it

1. Open the notebook in Google Colab.
2. Run each cell in order, starting with the first (topmost) cell.
3. Continue through the notebook sequentially until the final cell has finished executing.

## Runtime note

The dataset is large, so running the full project may take significant time:

- Approximately 45 minutes on the free GPU plan
- Approximately 10 minutes on the paid plan
